Set up a KVM

A KVM carries a machine's screen, keyboard and mouse somewhere else. Once one is set up, the rest of your equipment gets a “KVM port” choice.

The page you open to see its screens. rackmap links to it as the remote screen; the KVM asks for its own sign-in there. Leave empty for a KVM that isn't on the network.

How many machines it can be plugged into. A PiKVM on its own has one; with a PiKVM Switch, the switch's number of ports.

With an account, rackmap shows the screen itself, with keyboard, mouse and power buttons. rackmap signs in to check before saving, and stores the password encrypted on this rackmap server. Without one, rackmap just links to the PiKVM's page.

Leave the password empty to keep the saved one. Entering it again also accepts the PiKVM's current certificate.

Type text on the machine

The KVM types this on the machine's keyboard, for a password or a long command. It is sent as typed keys, assuming a US keyboard layout on the machine.

Power buttons

These press the machine's own front-panel buttons through the KVM. They only work if the KVM's power cable (ATX) is fitted to the machine.

Switches the machine on. If it is running, asks it to shut down.

Forces it off. Anything unsaved on the machine is lost.

Restarts it at once, without shutting down first.

Connect the management controller

Servers have a small built-in computer for management: iDRAC on Dell, iLO on HPE, BMC or IPMI on others. rackmap uses it to show power and health and to switch the server on and off. Its address and password are the controller's own, not the server's.

Not a server? Switches, firewalls and other gear with a serial cable to a console server get a “Console port” choice once a console server is set up, and a “KVM port” choice once a KVM is.

Leave the password empty to keep the saved one. Entering it again also accepts the controller's current certificate.

What the controller's SSH login runs to reach the server's serial console. Dell iDRAC: console com2. HPE iLO: vsp. Leave empty if you don't use it.

rackmap signs in to check these details before saving. The password is stored encrypted on this rackmap server.
